# Devbox

You are on a Namespace devbox (Ubuntu 24.04, user `devbox`). Setup source: github.com/vasileiosC/devbox.

## Available
- `gh` is logged in; git commits are signed automatically. Push over HTTPS.
- Go toolchain, gopls, golangci-lint (runs after every .go edit).
- Linear and Notion MCP.

## Where to look
- Cross-repo practices: Notion → Development → Dev Docs, rows where Applies to = All or this repo.

## Rules
- Never print or copy secrets.
- Repos are under /workspaces.
